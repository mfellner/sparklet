# README image provenance

| Asset | Source and treatment |
| --- | --- |
| `sparklet-cover.png` | Original AI-generated editorial illustration made for Sparklet on 2026-09-05. It is conceptual artwork, not a hardware photograph or evidence of actual UI behavior. |
| `head-overview.png` | User-supplied `IMG_2414.jpeg`, showing the head-node Overview on an earlier development build. |
| `worker-overview.png` | User-supplied `IMG_2415.jpeg`, showing the worker-node Overview on that build. |
| `node-details.png` | User-supplied `IMG_2417.jpeg`, showing the scrollable Details view on that build. |

The user requested that project screenshots be included in the GitHub README. Public photo copies have private EXIF/XMP/IPTC metadata removed. Direct square crops made with macOS sips exclude the desk, hands and USB cable; screen contents are not retouched. PNG output avoids another lossy JPEG encoding. Color profiles are retained where present. Originals remain outside the repository. Setup screenshots containing passwords, QR credentials or local Wi-Fi configuration were deliberately not selected for publication.

The photos retain the historical missing-glyph rectangle. The subsequent punctuation fix and the user’s successful physical confirmation are explained in the README rather than simulated by editing the screen content. New verified photos can replace these later, preserving the distinction between actual screenshots and generated artwork.

Crop rectangles in the original 960 × 1280 photos, expressed as x, y, width, height: head `(140, 305, 600, 600)`; worker `(110, 370, 610, 610)`; Details `(145, 385, 580, 580)`. Generated extraction trials were discarded and are not used in the README.
